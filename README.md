# منصة التقويم التجريبي – مباراة التعليم (سلك الابتدائي المزدوج) 🇲🇦

منصة ويب تفاعلية حديثة ومفتوحة، مبنية بـ **Vite + React + TypeScript + Tailwind CSS** ومدعومة بـ **Supabase** للنشر السريع عبر **Vercel** و **GitHub**.

---

## 🎯 مميزات المنصة

1. **المحاكاة الرسمية لمباراة التعليم بالمعاملات المعتمدة:**
   - **اللغة العربية** (المعامل: 6)
   - **اللغة الفرنسية** (المعامل: 6)
   - **الرياضيات** (المعامل: 6)
   - **العلوم والنشاط العلمي** (المعامل: 2)
   - **ديداكتيك المواد:** ديداكتيك العربية (3)، الفرنسية (3)، الرياضيات (3)، العلوم (3)
   - **علوم التربية ومستجدات المنظومة التربوية** (المعامل: 8)
   - حساب المعدل النهائي المرجح رسمياً من 20 نقطة.

2. **التقويم التشخيصي والتكويني (قبلي / بعدي):**
   - اختيار اختبار قبلي لكشف المكتسبات القبلية أو بعدي للمحاكاة النهائية.
   - فلترة حسب مادة معينة أو محاكاة شاملة لكافة المواد.

3. **التحليل الميتامعرفي (Metacognition):**
   - قياس درجة الثقة في كل جواب: `متأكد`، `متردد`، `تخمين`، `لا أعرف`.
   - رصد **"وهم المعرفة"** (عندما يكون المترشح متأكداً وجوابه خاطئ).
   - رصد **"تخمين الحظ"** وقياس وقت التفكير وعدد مرات التردد.

4. **لوحة إدارة وبنك الأسئلة السحابي:**
   - إضافة أسئلة فردية مع التعليل البيداغوجي.
   - رفع جماعي لآلاف الأسئلة دفعة واحدة عبر لصق مصفوفة JSON أو رفع ملف `.json`.
   - الربط السحابي المباشر مع قاعدة بيانات Supabase.
   - العمل التلقائي بنظام التخزين المحلي (LocalStorage) كخطة بديلة حتى بدون إنترنت أو بدون مفاتيح Supabase.

5. **تصدير النتائج:**
   - تصدير تقرير النتائج التفصيلي بصيغة `JSON` أو طباعته كـ `PDF`.

## 🛠️ دليل الإعداد والربط (Setup Guide)

### 1. إعداد قاعدة بيانات Supabase
1. توجه إلى [Supabase](https://supabase.com) وأنشئ مشروعاً مجانياً جديداً.
2. ادخل إلى **SQL Editor** في لوحة تحكم مشروعك.
3. افتح الملف [`supabase_schema.sql`](./supabase_schema.sql) في هذا المستودع، انسخ كامل محتواه والصقه في SQL Editor ثم اضغط **Run**.
   - سيقوم بإنشاء جدول `questions` وضبط سياسات الأمان وإدراج الأسئلة التأسيسية الـ 25.
4. اذهب إلى **Project Settings > API** وانسخ:
   - `Project URL`
   - `anon public key`

### 2. التشغيل المحلي (Local Development)
1. أنشئ ملف `.env.local` في مجلد المشروع وضع به مفاتيحك:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```
2. شغّل خادم التطوير:
   ```bash
   npm run dev
   ```

### 3. النشر على GitHub و Vercel
1. أنشئ مستودعاً جديداً على [GitHub](https://github.com/new).
2. ارفع المشروع بالأوامر التالية:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: CRMEF Quiz App"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. توجه إلى [Vercel](https://vercel.com) واضغط **Add New > Project** ثم اختر مستودعك من GitHub.
4. في قسم **Environment Variables** في Vercel، أضف:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. اضغط **Deploy**، وسيكون تطبيقك متاحاً برابط عام لجميع الزوار والمترشحين!
